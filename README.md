# NAVYHUB — Source Recovery Archive

This repository is private.

## Important
The ZIP file in `recovery/` is a preserved **NAVYHUB v0.1.0 foundation backup**. It is an older recovery snapshot using a Prisma/PostgreSQL foundation. It is **not** the current Supabase-connected Vercel application and must not be deployed over the active Vercel project.

Use this archive for source recovery and reference only. Before using any part of it, compare it with the current application and review environment variables, authentication, database schema, and access controls.
